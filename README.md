# BMW Motorsport

Página de presentación hecha con HTML, CSS y JavaScript puro (sin librerías).

## Estructura
- `index.html`: contenido de la página
- `css/style.css`: estilos y animaciones
- `js/script.js`: línea de tiempo, video de entrada, audio y efectos
- `assets/`: video, música y fotos

## Cómo verla
Abre `index.html` en el navegador.

## Cómo publicarla gratis en GitHub Pages
1. Sube todo el contenido de esta carpeta a un repositorio.
2. En el repositorio: Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save.
3. En un minuto tendrás tu link.

Proyecto personal, no es un sitio oficial de BMW.
